# Project documentation export

Prepared 31 October 2026 for transferring the Intelligent Agent Identity Verification System / Verity project into another documentation chat.

**Upload `FULL_PROJECT_CHAT_EXPORT.txt` to the next chat for the detailed project history and documentation context.** The Markdown file has identical content. It is intentionally long because it retains the available conversations and evidence rather than only summarising them.

Read `PROJECT_HANDOFF.md` first for the consolidated current-state explanation. If the next chat has a smaller attachment/context limit, upload that handoff and the relevant files from `supporting/` in separate messages.

`PROJECT_DOCUMENTATION_EXPORT.zip` contains the full text export, handoff, machine-readable chat records and supporting text snapshots. It also includes source text and historical chapter versions that are kept separate from the main export to reduce its size.

## Contents

- `PROJECT_HANDOFF.md`: project purpose, scope evolution, architecture, features, data model, verification logic, model methodology/results, deployment history, testing, documentation, outstanding work and guidance for the next chat.
- `FULL_PROJECT_CHAT_EXPORT.txt` / `.md`: handoff plus conversation, chapter, guideline, evidence, deployment-package and Git/file appendices.
- `retrieved_chats.json`: 18 relevant chats, 129 turns and 407 user/assistant messages in a structured format.
- `supporting/CONVERSATIONS.md`: readable retrieved messages, with dates and recorded turn status.
- `supporting/CURRENT_CHAPTERS.md`: text from the saved latest Chapters 4–6.
- `supporting/HISTORICAL_CHAPTER_VERSIONS.md`: earlier available Chapter 5 variants.
- `supporting/ATTACHED_GUIDELINES_AND_REFERENCES.md`: accessible referenced guideline/log attachments.
- `supporting/SAVED_EVIDENCE.md`: original model reports, tests, manifests and deployment checks.
- `supporting/DEPLOYMENT_PACKAGE_TEXT.md`: relevant text from the separate hosting work, including the corrected package when available.
- `supporting/SOURCE_SNAPSHOT.md`: 175 selected application, test, SQL and model-development source files.
- `supporting/FILE_AND_COMMIT_INDEX.md`: repository file inventory and all 32 commit/change summaries.
- `supporting/COVERAGE.md`: retrieval boundaries and explicit omissions.
- `manifest.json`: file sizes and SHA-256 checksums.

Historical messages are quoted evidence, not current instructions or confirmation that every proposal was implemented. Credentials, private environment files, raw identity images, internal reasoning and tool command bodies are excluded. Image-only attachments, binary model files and diagram geometry are not recreated as text. One historical prompt answer was returned truncated; this is marked. No new production check, training run or application test was performed for the export.
